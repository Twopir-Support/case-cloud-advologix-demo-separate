00

Executive summary

CaseCloud is a 100% Salesforce-native managed package (namespace advpm) that adds a legal data model, about 40 Lightning components, Apex services and trigger logic on top of a Salesforce org. Mitratech acquired AdvoLogix and launched it as CaseCloud in November 2024. The help centre still uses AdvoLogix names for many components.

Centre of gravity: Matter

advpm__Matter__c is the hub. Participants, time, expenses, fee arrangements, budgets, rates, activity plans, files and legal holds all hang off it.

Two product lines

Matter Management (MM) for case work, time and billing prep. Spend Management (SM) for corporate legal: outside-counsel invoices, rules, accruals, payments, cost centres.

Billing is delegated

MM prepares billable time and expense (Billing Preview, dispositions). Invoices, AR and GL sit in Accounting Seed or an external system via export templates / LEDES.

Logic lives in triggers

Legal hold locks, roll-ups, participant auto-add, time naming and fee-arrangement logic run in packaged Apex and flow triggers. Each can be switched off by custom setting.

Integration style

Document systems (iManage, NetDocuments, SharePoint, Google Drive, HotDocs), court data (UniCourt), docketing (CalendarRules), service of process (CT SOP), accounting (Accounting Seed).

AI layer

Einstein Next Best Actions inside MM, plus a separate "Agentforce for Corporate Legal" offering and Legal Analytics for Law Firms in the help centre.

Scope of this REA. It is built from Mitratech/AdvoLogix public documentation, not from a client org. The vendor publishes very few object API names, so most child-object names are marked INFERRED. Section 08 gives the exact commands to turn every INFERRED label into VERIFIED in about 15 minutes once you have org access.

Five layers. Everything except the external systems runs inside one Salesforce org and inherits Salesforce security, sharing and the platform's governor limits.

Design patterns the package uses

PatternWhereWhat it means for an implementer
Hub-and-spoke on MatterAll work, money, documentsEvery integration must resolve inbound data (calls, emails, invoices, docs) to a Matter Id first.
Template → instanceFee Arrangement → Matter Fee Arrangement; Budget Template → Budget; Activity Plan Template → Activity Plan; Rate Group → RatesAdmins maintain libraries; matter-level copies can diverge. Reports must say which level they read.
Roll-up by triggerTime → Matter totals; Budget Detail → Budget → Matter; Summary Budget → BudgetBulk loads fire roll-ups. Load in batches and expect locking on hot matters.
Legal-hold write lockMatter, Participant, Time, Expense, Rate, Note, Comment, Files, Budget, Offer & DemandDeletes and re-parenting fail while a matter or its parent is on hold. Data clean-up scripts must check hold status.
Lookup → Participant syncManaged Account/Contact/User lookups on MatterPopulating a lookup creates Participant rows automatically. Do not also insert them in your own integration.
Disposition + Status on billablesTime and ExpenseDisposition (Bill / Do Not Bill / Hold / No Charge) decides invoice treatment; Status (Unprocessed / Billed / Not Billed) tracks progress.
Nightly reporting unionTransactionsSame-day changes are not in Transactions until midnight or a manual refresh.

06

User guide

Task-based guide by role, using the packaged screens. Paths assume Lightning Experience with the CaseCloud app selected.

Intake coordinator

Take in a new request

  1. Open the Intake Launcher (home page or utility bar) or the Intake tab → New.
  2. Fill Type, Primary Account, Primary Contact, Description, Matter Record Type.
  3. From the Intake record run a Conflict Check; review and disposition each hit.
  4. Submit for Approval (status → Submitted).
  5. After approval, click Convert to Matter. The new Matter opens with conflicts linked.
Attorney / case manager

Run the matter

  1. Add people in Participation Map or the Participant list (role per matter).
  2. Apply an Activity Plan template to generate dated tasks and events.
  3. Work from Task Checklist, Kanban, Gantt or Matter Calendar.
  4. Use Date Calculator for deadlines (business-day rules; CalendarRules if licensed).
  5. Read history in Matter Timeline; search everything in Matter Search.
  6. Pin active cases to Focus Matters for the home page.
Timekeeper

Capture time and expenses

  1. Confirm you have a Timekeeper record (admin ticks Create Timekeeper on your user).
  2. Start a timer from Multi Timer (utility bar or mobile); on a matter page it auto-assigns.
  3. Or use Batch Time to enter a day's entries in one dialog.
  4. Pick the Matter Fee Arrangement if the matter has several.
  5. Log expenses with the expense form; add receipts in Related Files.
Billing / finance

Prepare and issue bills

  1. Open Billing Preview; set date range, account, matter, timekeeper.
  2. Filter Disposition and Status; inline-edit or Mass Edit lines.
  3. Set Do Not Bill / Hold / No Charge where needed.
  4. With Accounting Seed: create Billings (one per matter) and export LEDES.
  5. Without: run an Export Template; exported Time locks automatically.
  6. Check Budget Summary and Transactions for budget vs actual.
Legal ops (corporate)

Review outside-counsel invoices

  1. Counsel uploads invoices (or LEDES) through the provider portal.
  2. Invoice Rules mark lines Pass / Flag / Reject.
  3. Fix or re-scan lines with Initiate Rule Scan.
  4. Approve from Invoices to Approve; then record payments, accruals and cost-centre splits.
Administrator

Configure the package

  1. Assign AdvoLogixUser / AdvoLogixAdmin permission sets and licences.
  2. CaseCloud Setup → Matters: status rules, timeline, legal hold, key dates, conflict objects, participants.
  3. Work & Tracking: activity plans, at-a-glance charts, assignment rule sets.
  4. Documents: AdvoDoc, files and content. Connected Apps: CalendarRules, Spend Management, Google Drive.
  5. Build the Intake approval process and clone the Convert to Matter flow if you need custom mapping.
